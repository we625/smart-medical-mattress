# 🛏️ المفرش الطبي الذكي

نظام محاكاة ذكي لمراقبة ضغط المفرش الطبي وكشف مناطق الخطر لقرح الفراش.

> [!IMPORTANT]
> **البيانات المستخدمة في هذا النظام هي بيانات محاكاة توليدية بالكامل.**
> النظام أداة **داعمة للقرار** فقط ولا يُستخدم للتشخيص الطبي.
> لا يُغني عن التقييم السريري المتخصص.

---

## 📋 وصف المشروع

يحاكي هذا المشروع مفرشًا طبيًا ذكيًا مزوّدًا بحسّاسات ضغط (مصفوفة 16×8)
وحسّاسات حرارة ورطوبة. يستخدم النظام خوارزمية **Isolation Forest** لكشف
الأنماط الشاذة في توزيع الضغط، مع آلية تنبيه ذكية لا تُطلَق إلا عند استمرار
الشذوذ لعدة قراءات متتالية — لتقليل الإنذارات الكاذبة.

### التقسيم التشريحي لمصفوفة الضغط (١٦×٨)

- **الرأس**: الصفوف ١–٢ (الأعمدة الوسطى ٣–٦)
- **الكتفان**: الصفوف ٣–٤ (الأعمدة ٢–٧)
- **الظهر**: الصفوف ٥–٦ (الأعمدة الوسطى ٣–٦)
- **الذراعان واليدان**: الصفوف ٤–٩ (الأعمدة الطرفية اليمنى ١–٢ واليسرى ٧–٨)
- **الحوض**: الصفوف ٧–١٠ (الأعمدة الوسطى ٣–٦)
- **الفخذان**: الصفوف ١١–١٣ (الأعمدة الوسطى ٣–٦)
- **الساقان والكعبان/القدمان**: الصفوف ١٤–١٦ (الأعمدة الوسطى ٣–٦)

### السيناريوهات المتاحة

| السيناريو | الوصف |
|---|---|
| **السيناريو الطبيعي** | توزيع ضغط متوازن وحرارة ورطوبة ضمن النمط الطبيعي للمريض |
| **ضغط مستمر على الحوض** | ارتفاع مستمر للضغط في منطقة الحوض والعجز (الصفوف ٧–١٠) |
| **ضغط على الكعبين والساقين** | تركّز الضغط في الصفوف السفلية لمنطقة الساقين والكعبين والقدمين (الصفوف ١٤–١٦) |
| **ضغط جانبي على الكتف والذراع واليد** | يحاكي استلقاء المريض طويلاً على جانب واحد مع ارتفاع الضغط على الكتف والذراع واليد |
| **تعرق ورطوبة وحرارة مرتفعة** | ارتفاع ملحوظ في رطوبة السطح وحرارته يستدعي التهوية والتبريد الآمن |
| **برودة وانخفاض حرارة السطح** | انخفاض غير معتاد في حرارة السطح يستدعي التدفئة الآمنة |
| **خطر مركّب (ضغط + رطوبة + حرارة)** | سيناريو طارئ يجمع بين الضغط المستمر والتعرق وارتفاع الحرارة (أعلى خطر لتقرحات الجلد) |

```

├── .streamlit/
│   └── config.toml    # إعدادات الثيم النهاري (الألوان الأساسية)
├── vendor/            # مكتبتا Three.js و OrbitControls للعرض ثلاثي الأبعاد محليًا
├── simulator.py       # مولّد بيانات المحاكاة والتأثير التدريجي لوحدة التكييف

├── requirements.txt   # المكتبات المطلوبة
└── README.md          # هذا الملف
```

## 🚀 خطوات التشغيل

### 1. إنشاء بيئة افتراضية (اختياري لكن مُستحسن)

```bash
python3 -m venv venv
source venv/bin/activate        # على macOS/Linux
# أو
venv\Scripts\activate           # على Windows
```

### 2. تثبيت المكتبات المطلوبة

```bash
pip install -r requirements.txt
```

### 3. تشغيل لوحة التحكم

```bash
streamlit run dashboard.py
```

ستُفتح لوحة التحكم تلقائيًا في المتصفح على العنوان `http://localhost:8501`.

> [!NOTE]
> شغّل الأمر من **داخل مجلد المشروع** حتى يقرأ Streamlit ملف الثيم `.streamlit/config.toml`.
> يُحمَّل خط Cairo من Google Fonts، لذا يلزم اتصال بالإنترنت لظهوره؛ وبدونه يُستخدم خط النظام.

## 🖥️ استخدام لوحة التحكم

1. **راجع بطاقة ملف المريض الافتراضي** أعلى اللوحة للتعرف على النمط الطبيعي المتعلّم بالذكاء الاصطناعي.
2. **اختر السيناريو** من القائمة المنسدلة (ينعكس فورًا على المجسم ثلاثي الأبعاد، والخريطة الحرارية، والمنحنيات، وسجل التنبيهات).
3. **تحكّم بوحدة التهوية والتبريد والتدفئة الآمنة** (`تلقائي`، `تهوية وتبريد`، `تدفئة آمنة`، `إيقاف`) وحدّد درجة الحرارة المستهدفة الآمنة (`32.5 – 36.0 °م`).
4. **استكشف التبويبين البصريين**:
   - **عرض 3D تفاعلي للطبقات** – تدوير وتقريب بالماوس، زر وشريط لتفكيك الطبقات الخمس الهندسية بسلاسة مع تسمياتها العربية، زر إظهار/إخفاء مجسم المريض الشفاف، ومراقبة تيارات الهواء الزرقاء/التوهج الدافئ ومؤشر LED على وحدة التحكم الجانبية.
   - **خريطة الضغط 2D** – مصفوفة الضغط `16×8` التفصيلية مع تحديد المنطقة المصابة بإطار متقطع.
5. **راقب المنحنيات وسجل التنبيهات وتوصيات التمريض**، واضغط **ولّد قراءات جديدة** لملاحظة الأثر التدريجي للتكييف، أو **إعادة تعيين الجلسة** للبدء من جديد.

---

## 🧠 آلية كشف الشذوذ

- يتدرب نموذج **Isolation Forest** على بيانات السيناريو الطبيعي فقط.
- عند ورود قراءة جديدة، يُصنّفها النموذج (طبيعية أو شاذة).
- **لا يُطلق التنبيه فورًا** عند أول قراءة شاذة، بل ينتظر حتى تتكرر
  لعدة قراءات متتالية (العتبة الافتراضية: 3 قراءات).
- هذا يقلّل الإنذارات الكاذبة ويزيد موثوقية التنبيهات.
